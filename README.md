# ⚡ Electricity Billing System (GUI + MySQL)

## 📌 Project Overview
The **Electricity Billing System** is a desktop-based application developed to automate electricity bill generation and management.  
This system uses a **Graphical User Interface (GUI)** for user interaction and a **MySQL database** for secure data storage.  
It helps manage customer details, meter readings, bill calculation, and billing history efficiently while reducing manual effort and errors.

---

## 🎯 Key Features
- GUI-based user-friendly interface  
- Add, update, and manage customer details  
- Store and manage meter readings  
- Automatic electricity bill calculation  
- Monthly bill generation  
- Billing history stored in MySQL database  
- Accurate and reliable data handling  

---

## 🛠️ Technologies Used
- **Programming Language:** Java  
- **GUI Framework:** Java Swing / AWT  
- **Database:** MySQL  
- **IDE:** IntelliJ IDEA  
- **Database Connectivity:** JDBC  
- **Concepts:** OOP, Event Handling, SQL Queries  

---

## ⚙️ System Workflow
1. Launch the application  
2. Add customer information via GUI  
3. Enter monthly meter readings  
4. System calculates electricity bill automatically  
5. Bill data is stored in MySQL  
6. Users can view billing history  

---

## 🗄️ Database Design
- **Customer Table:** Stores customer personal details  
- **Meter Table:** Stores meter readings  
- **Bill Table:** Stores bill amount, units consumed, and billing date
